# Staging source library

Generated by `npm run sync:staging`. It preserves core-page text and an image manifest from the supplied staging website. Images live under `public/assets/source/staging/images/`.

`npm run sync:blogs` captured the 30 articles displayed on the old staging Blogs page. It wrote a lightweight `blogs-index.json`, one lazily loaded detail file per article under `blog-articles/`, a full archival `blogs.json`, and local copies of article images under `public/assets/source/staging/blog-images/`. Do not rerun that bulk sync to add a single new article; it would overwrite the current library.

The 15 October 2026 live-site article "When Does a Remote Support Role Require Industry Experience?" was added separately, bringing the local library to 31. The 26 October 2026 article "Why Niche Roles Are Moving Into the Virtual Recruitment Market" was added the same way, from the live site's public article feed, bringing it to 32; its featured image is in the same folder. It was posted directly on VOA staging, so it has no import file. Its featured image is under `public/assets/source/live/blog-images/`. A single-post WordPress WXR import is under `wordpress-theme/imports/`.

`npm run sync:clients` audits the live homepage carousel and maps all 30 client logos to their downloaded local files in `clients.json`.

These are source-reference assets, not automatically approved final assets. Confirm ownership, accuracy, consent, and production suitability with Virtual Office Angels before launch.
