# VOA Layout 1

Stage 1 design prototype for the Virtual Office Angels website rebuild.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Scope

The React/Vite/TypeScript mockup of the approved Layout 1 (deployed on Vercel), and the custom WordPress
theme that reproduces it (`wordpress-theme/`). The mockup stays the visual reference until the WordPress
site is approved.

`claude.md` holds the project context and working rules. [`docs/README.md`](docs/README.md) maps the
documentation; what is left before launch is in the go-live checklist and the launch plan in
`docs/wordpress-integration/`.
